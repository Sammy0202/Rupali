## Publish free using GitHub Pages
1. Sign in or create a free account at https://github.com/.
2. Create a **public** repository named `wedding-invitation`.
3. Upload `index.html` and the complete `assets` folder.
4. Open **Settings → Pages**.
5. Select **Deploy from a branch**, choose `main` and `/(root)`, then Save.
6. GitHub will provide your public website URL after publishing.

No paid domain or hosting is required. The RSVP opens WhatsApp with a pre-filled message; guests must tap Send themselves.
